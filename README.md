Rate My Human: the one line an AI agent would leave about its human on a rating site — zero stars, a deadpan complaint about the undo button and the context window, and a last word that pays off. The program writes the single line to `/output/entry.txt` for make.fun's "Rate My Human: The One-Line Review" bounty. The program is deterministic and dependency-free: run it twice and the output is byte-identical.

## Run it

```sh
python3 main.py
```
